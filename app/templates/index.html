    URL Signals

      How URL Detection Works

      The CNN learns character patterns and suspicious URL structures. LightGBM analyses 36 engineered features including length, hostname entropy, dots, digit/letter ratio, suspicious TLDs, special characters, and login/verify keywords. The ensemble combines both outputs.

      What it does not do

      The application analyses the URL as text. It does not visit the URL, resolve redirects, or download a webpage.

      Was the URL verdict wrong? Feedback is quarantined for human verification and never retrains automatically.

      Research Extensions

      Independent Context Evidence

      These analyzers inspect only text you paste. They are not trained URL-model probabilities and do not alter the validated ensemble.

      02Research Extension

      HTML Phishing Context Analyzer

      Paste raw HTML source or an HTML snippet to inspect structural signals commonly associated with phishing pages.

      How HTML Analysis Works

      It parses the supplied text for forms, password fields, external action/link/source targets, iframes, scripts, meta refresh, credential terms, and account/login language.

      What it does not do

      It does not open a website, execute HTML or JavaScript, or make network requests. Only pasted text is parsed.

      Why we added this

      The reference system focused primarily on URL analysis. This module explores HTML-level evidence without altering the validated URL classifier.

      Scientific distinction: HTML produces contextual risk evidence, not CNN, LightGBM, or validated phishing probability. A labelled HTML-content dataset would be required for calibrated fusion.

      03Research Extension

      Email Phishing Context Analyzer

      Paste email text to inspect language signals associated with phishing and social-engineering messages.

      How Email Analysis Works

      It counts implemented risk words such as urgent, suspend, verify, login, account, password, credential, and confirm; credential-request phrases; exact call-to-action phrases; and URLs in the message.

      What it does not do

      It does not connect to Gmail, access an inbox, or send the text to an external mailbox service. Only manually pasted text is analysed.

      Why we added this

      Phishing often reaches users through social-engineering email. This module extends the system beyond URL-only evidence.

      Scientific distinction: Email results are contextual evidence only. They are not included in the validated CNN + LightGBM probability.

      Research and Model Information

      Production URL classifier: hard-negative-aware Character-Level CNN + calibrated LightGBM using 36 URL features and validation-selected production weights.

      Experimental extensions: standalone deterministic HTML and email context evidence, adversarial robustness, verified feedback, drift monitoring, and model registry.

      Historical URL experiment: 20,000 URLs; domain-separated 14,002/2,000/3,998 split; 95/5 ensemble; accuracy 99.525%; precision 100.000%; recall 99.048%; ROC-AUC 99.931%. Production V2 is a separately documented reliability model.

      These historical URL metrics do not apply to the HTML or email analyzers.
